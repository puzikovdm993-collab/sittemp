# WebSocket Пример для новичков

Этот проект содержит полный рабочий пример WebSocket сервера и клиента для изучения технологии WebSocket.

## 📁 Структура проекта

```
websocket-example/
├── server.py          # WebSocket сервер на Python
├── client.html        # Веб-клиент с красивым интерфейсом
├── GUIDE.md           # Подробное руководство для новичков
└── README.md          # Этот файл
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install websockets
```

### 2. Запуск сервера

```bash
python server.py
```

### 3. Запуск клиента

Откройте `client.html` в браузере (можно просто перетащить файл в окно браузера).

## 🔧 Тестирование рассылки

Чтобы протестировать рассылку сообщений:

1. Откройте `client.html` в нескольких вкладках браузера
2. Подключите все вкладки к серверу
3. В одной из вкладок нажмите "Тест рассылки"
4. Сообщение появится во всех подключенных вкладках!
