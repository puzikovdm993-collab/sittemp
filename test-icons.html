Тест анимации иконок

Иконка папки

Статус: Неактивна

Иконка синхронизации

Статус: Неактивна

Примеры использования в коде

1. Активировать анимацию папки на 3 секунды:

iconAnimation.activateFolderAnimation('#folder-icon', 3000);

2. Активировать анимацию синхронизации на 5 секунд:

iconAnimation.activateSyncAnimation('#sync-icon', 5000);

3. Активировать обе анимации одновременно:

iconAnimation.activateAllAnimations({
    folder: '#folder-icon',
    sync: '#sync-icon'
}, 4000);

4. Деактивировать анимацию досрочно:

iconAnimation.deactivateFolderAnimation('#folder-icon');
iconAnimation.deactivateSyncAnimation('#sync-icon');

5. Деактивировать все анимации:

iconAnimation.deactivateAllAnimations();

6. Проверить статус анимации:

if (iconAnimation.isAnimationActive('#folder-icon')) {
    console.log('Анимация активна');
}
